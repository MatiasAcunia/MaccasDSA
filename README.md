# MaccasDSA

Proyecto personal en Java para aprender Estructuras de Datos y Algoritmos, implementando cada módulo con commits propios.

## Dos fases
**Fase 1 — aprender e implementar:** estudiar representación e invariantes, definir operaciones, codificar cada TAD o estructura, probar y documentar sus costos. El alumno escribe el código. No convertir cada módulo en librería pública por separado.

**Fase 2 — construir la librería:** una vez cerrados los 18 módulos acordados, refactorizar y unificar sus APIs, genéricos, documentación y pruebas sin tirar lo ya construido. Las extensiones opcionales no bloquean la fase 2.

TAD = contrato/comportamiento; estructura = representación/implementación. Stack y Queue son TADs; una linked list y un heap son implementaciones/estructuras concretas.

**Ritmo:** 2–3 sesiones semanales, sin obligación de terminar una estructura por semana. Para temas nuevos, primero explicación o video de cómo funciona, después implementación propia sin copiarlo línea a línea. Commits pequeños por avance funcional.

Ver [roadmap](docs/ROADMAP.md), [estado](docs/ESTADO.md), [sesiones](docs/SESIONES.md) y [fase 2](docs/FASE_2_LIBRERIA.md).

Java 21 + Maven + JUnit 5 para tests. Este scaffold aún no tiene código de TADs ni tests: compilar un proyecto vacío no certifica ningún módulo.
