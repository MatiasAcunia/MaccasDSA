# MaccasDSA

Data structures and algorithms implemented in Java.

## Requirements

- JDK 21
- Maven 3.9+

## Build and test

```bash
mvn test
```

## Project layout

- `src/main/java/dev/maccas/dsa/` — implementations
- `src/test/java/dev/maccas/dsa/` — tests
- `docs/tads/` — technical specifications

See the [module index](docs/ROADMAP.md).
