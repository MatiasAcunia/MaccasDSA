# 17 — SegmentTree

## Scope

Consultas y actualizaciones de rangos.

## Operations

build; rangeQuery; update; size.

## Invariants

cada nodo resume su segmento; operación asociativa definida.

## Verification

rango completo; extremos; tamaño no potencia de dos.

## Complexity

build O(n); rangeQuery/update O(log n).
