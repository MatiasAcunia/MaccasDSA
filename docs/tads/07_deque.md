# 07 — Deque

## Scope

TAD de doble extremo.

## Operations

addFirst; addLast; removeFirst; removeLast; peekFirst; peekLast; size.

## Invariants

front/back válidos; enlaces consistentes o buffer circular.

## Verification

intercalar ambos extremos; vacía; uno; wrap-around.

## Complexity

extremos O(1) amortizado.
