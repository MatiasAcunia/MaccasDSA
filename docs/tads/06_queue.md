# 06 — Queue

## Scope

TAD FIFO; buffer circular o lista.

## Operations

enqueue; dequeue; peek; isEmpty; size.

## Invariants

FIFO y coherencia front/rear; wrap-around si array.

## Verification

vacía; uno; varias vueltas del buffer; intercalado.

## Complexity

O(1) amortizado en extremos con implementación elegida.
