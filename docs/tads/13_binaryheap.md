# 13 — BinaryHeap

## Scope

Priority Queue con heap binario sobre array.

## Operations

offer; peek; poll; size; buildHeap.

## Invariants

padre con prioridad acorde a hijos; árbol completo en array.

## Verification

duplicados; heapify; extraer hasta vacío.

## Complexity

peek O(1); offer/poll O(log n); buildHeap O(n).
