# 11 — BinarySearchTree

## Scope

Árbol de búsqueda no balanceado.

## Operations

put; get; containsKey; remove; inorder; size.

## Invariants

key izquierda < actual < derecha según política de duplicados.

## Verification

insertados en orden; remove de 0/1/2 hijos; vacío.

## Complexity

operaciones O(h); peor O(n) si degenerado.
