# 05 — Stack

## Scope

TAD LIFO sobre array o lista.

## Operations

push; pop; peek; isEmpty; size.

## Invariants

LIFO; pop/peek en vacío tienen contrato definido.

## Verification

intercalado de pushes/pops; vacía; muchos elementos.

## Complexity

O(1) por extremos; amortizado si array dinámico.
